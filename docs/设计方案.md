## 1. 项目定位与已确认需求

构建一套用于量化研究的 A 股日频截面因子自动挖掘系统：

| 需求项 | 已确认决策 |
|---|---|
| 挖掘算法 | **双引擎并行**：GP（遗传规划，表达式树演化）+ RL（AlphaGen 式，PPO 逐 token 生成表达式），共享算子库、评估器与因子库 |
| 股票池 | 全 A 股（沪深主板 + 创业板 + 科创板，SecuMarket∈{83,90}，实测现存约 5152 只），剔除 ST/\*ST、停牌、次新（上市不足 120 交易日）；北交所(18)默认剔除、股转系统(81)一律排除（实测库内含 6259 只挂牌公司，必须过滤）（可配置） |
| 预测目标 | 未来 **10 个交易日**收益的 RankIC 为主适应度，评估报告兼报 1/5/20 日 |
| ⭐ 核心展示指标 | **IC/IR（ICIR = IC 均值 / IC 标准差）**——因子列表默认按 10 日 ICIR 排序，详情页突出显示（含年化 ICIR = ICIR × √(252/H)） |
| 因子库 | 持久化存储，支持**增、删、改、查**；交互采用 **Web 可视化界面**（Streamlit，本地网页），不做 CLI |
| 技术路线 | **Python 挖掘管线** + 聚源直连取数（官方 FAQ 明确认可"通过各类编程语言执行 SQL 查询"）；与 IRS(C#) 回测系统解耦，后续可扩展"因子→C# 策略"导出 |

## 4. 数据层设计（聚源表 → 特征矩阵）

**连接**：`pymssql`（pip 装入 `D:\python`，自带 TDS 协议实现，**无需向 C 盘装 ODBC 驱动**；系统现存旧版 "SQL Server" ODBC 驱动可作 pyodbc 备用通道）。客户端只发 `SELECT`（代码层白名单校验，遵守技能包"不得对数据库造成任何改动"的规定）；连接失败时提示"关闭代理/梯子"（环境文档明确警告）。

**表与用途**（均来自表字典调研，字段已核实）：

| 用途 | 表 | 关键字段 |
|---|---|---|
| 证券主表/股票池 | `SecuMain` | InnerCode, SecuCode, SecuMarket(83/90), SecuCategory=1, ListedDate, ListedState |
| 交易日历 | `QT_TradingDayNew` | TradingDate, IfTradingDay, SecuMarket=83 |
| 日行情 OHLCV | `QT_DailyQuote` ∪ `LC_STIBDailyQuote`（**实测确认**：科创板 688xxx 不在 QT_DailyQuote，必须双表 UNION；本库无 DZ_ 合表；QT_DailyQuote 查询无授权障碍） | Open/High/Low/ClosePrice, PrevClosePrice, TurnoverVolume/Value |
| 复权 | 优先直取 `QT_PerformanceData.BackwardPrice`（**实测核验**：= Close×AdjustingFactor+AdjustingConst，与 `QT_AdjustingFactor` 完全吻合）；O/H/L/VWAP 施加同一线性变换；科创板经 `LC_STIBAdjustingFactor`/`LC_STIBPerformance`（M1 探测字段） | BackwardPrice; ExDiviDate, AdjustingFactor, AdjustingConst |
| 换手/市值/停牌 | `QT_StockPerformance` | TurnoverRate, TurnoverRateFreeFloat, TotalMV, NegotiableMV, **Ifsuspend** |

**同步策略**：按 `TradingDay` 增量拉取 → `data_cache\` 下按表/按年分区 parquet（zstd 压缩）。默认历史区间 **2016-01-01 起**；**数据终点由同步器逐表探测 MAX(TradingDay) 取交集**（实测行情/估值/指数表至 2025-09-05，官方口径 2024-12-31）。**实测本库为字典 1727 张表中的 704 张子集**（`PIT_*`、`FIN_Derivative/FIN_TTMDerivative`、`DZ_*` 合表、`CS_StockAdjPerformance` 均缺失；财务三表 `LC_*All`、`LC_MainIndexNew`、单季表等均在），数据层启动时做表存在性自检。全 A 十年日频数据量约 1~2 GB，D 盘 161 GB 充裕。

**特征矩阵**：对齐为 `(T 交易日 × N 股票)` 的 float32 矩阵（每特征约 55 MB，内存友好），股票轴用 InnerCode。v1 基础特征端子 **14 个**：`open/high/low/close`（后复权）、`vwap`、`volume`、`amount`、`turnover`（换手率）、`free_turnover`、`total_mv`、`neg_mv`、`ep_ttm`(=1/PE)、`bp`(=1/PB)、`sp_ttm`(=1/PS)——估值取倒数避免负 PE 断点。基本面 PIT 特征作为二期扩展：官方 `PIT_*`/`FIN_*` 表实测不在本库，改用 `LC_BalanceSheetAll`/`LC_IncomeStatementAll`/`LC_CashFlowStatementAll`/`LC_MainIndexNew`（均实测存在）按 `InfoPublDate` 自建 PIT 对齐防未来函数，数据层预留接口。

**掩码体系**（评估与回测共用）：
- `universe_mask`：非 ST、非停牌、上市 ≥120 交易日、未退市；
- `tradable_mask`：在 universe 基础上再剔除 t+1 日一字涨停（买入不可行），用于分层回测。

## 5. 表达式与算子层（两引擎共享）

**不用 gplearn**（已停维护，与 numpy 2.4/pandas 3.0 不兼容，且不支持面板时序算子）——自研轻量 AST + 算子库：

- **终端**：14 个特征 + 窗口常量集 {3, 5, 10, 20, 40, 60}；
- **逐元素算子**：`add, sub, mul, div(安全), neg, abs, slog(符号对数), sign, sqrt, inv`；
- **时序算子**（沿 T 轴滚动）：`ts_mean, ts_std, ts_sum, ts_min, ts_max, ts_rank, ts_delay, ts_delta, ts_ret, ts_corr, ts_cov, ts_ema, ts_med, ts_slope, decay_linear`；
- **截面算子**（沿 N 轴逐日）：`cs_rank, cs_zscore, cs_demean, cs_scale, cs_indneutral(行业中性)`；
- 全部基于 numpy/pandas 向量化实现，NaN 感知；`ts_rank/ts_corr` 等重算子用滑窗向量化 + numba（已装）加速；
- **合法性约束**：窗口参数只能取常量集；最大深度 8、最大节点 24（可配置）；
- **序列化**：字符串式 `cs_rank(ts_corr(cs_rank(close), cs_rank(volume), 10))`，配套解析器可从库中反解重算；规范化哈希用于表达式级查重。

## 6. 评估体系（⭐ICIR 为核心）

**收益标签**：`ret_H(t) = C_adj(t+1+H)/C_adj(t+1) − 1`（t 日收盘后算因子、t+1 收盘建仓，杜绝前视）。H ∈ {1,5,10,20}，主适应度用 H=10。

**因子预处理**：MAD 去极值 → 可选行业+市值中性化（配置开关）→ 截面 zscore。

**指标集**（每个 H 各算一套，入库全存）：
- RankIC 日序列 → **IC 均值、IC 标准差、ICIR、年化 ICIR(×√(252/H))**、IC t 值、IC>0 胜率；
- 分层回测（10 组，等权，日频滚动）：各组年化收益、**多空年化/夏普/最大回撤**、单调性；
- 换手代理：因子截面秩自相关(lag=H)、Top 组换手率；
- 覆盖率（有效值占比）；与库内活跃因子的最大 |值相关|。

**时间切分**（防过拟合，研究级要求；已按实测数据终点修订）：
- 训练段 2016-01-01 ~ 2022-12-31（引擎适应度只看这段）；验证段 2023-01-01 ~ 2024-12-31（入库门槛，处于官方数据口径内）；观察段 2025-01-01 ~ 实测数据终点（约 2025-09-05，仅展示参考，不参与任何筛选）。

**引擎内适应度**：`fitness = |RankIC10_train| − λ₁·max|corr(候选, 因子池)| − λ₂·节点数`（默认 λ₁=0.1，λ₂=0.001）。引擎内用降采样快速评估（隔日采样），过阈值候选再全量评估。

**入库门槛**（默认值，均可在 config 调整）：训练段 |RankIC10| ≥ 0.02 且 |ICIR10| ≥ 0.30；验证段 IC 同号且 |ICIR10| ≥ 0.15；与库内活跃因子 |corr| ≤ 0.7；覆盖率 ≥ 60%。

**方向约定**：因子统一调整为 IC 为正方向入库（记录原始符号）。

## 7. GP 引擎

- 种群 500，代数 50（可配置）；ramped half-and-half 初始化（深度 2–6）；
- 锦标赛选择(20) + 子树交叉(0.65) + 子树/点/hoist 变异(0.2/0.1/0.05) + 精英保留(10)；
- 简约压力（节点数惩罚）+ 表达式哈希查重 + 与种群/因子池的值相关性去重；
- `concurrent.futures` 进程池并行评估（Windows spawn 模式：worker 启动时一次性加载共享特征矩阵，避免反复拷贝）；
- 每代日志（最优/中位适应度、入池数）写 `artifacts\logs\`，支持断点续跑（检查点）。

## 8. RL 引擎（AlphaGen 式）

- **MDP**：状态 = 已生成 token 前缀；动作 = 下一 token（算子/特征/窗口常量/END），**逆波兰(RPN)** 构造，动作掩码保证任意时刻只能选语法合法 token；最大长度 24；
- **策略网络**：小型 Transformer 编码器（2 层，d_model=128，4 头）+ 价值头——CPU 即可训练（T1000 4GB 可选用，非必需，默认装 CPU 版 torch 省空间）；
- **自研 PPO**（约 300 行，只依赖 torch）：批量 rollout（128 回合/批）、GAE、clip=0.2、熵奖励 0.01、终端奖励制。不引入 stable-baselines3/gymnasium（其与 Python 3.13 + numpy 2.4 组合兼容性风险高，且本 MDP 极简，自研更可控）；
- **奖励**：v1 与 GP 适应度同构（`|RankIC| − 相关性惩罚 − 复杂度惩罚`，保证两引擎评价一致可比）；预留 AlphaGen 原版"因子池组合 IC 增益"奖励接口（config 切换）；
- 训练曲线、已发现表达式定期落盘；检查点续训。

## 9. 因子库（持久化 + 增删改查）

- **元数据**：SQLite（WAL 模式，挖掘进程与 Web 界面并发安全），经 SQLAlchemy（已装）访问；
- `factors` 表：id、name（自动 `GP_20260717_0001` 式，可改）、expression、engine(GP/RL/manual)、status(active/candidate/archived)、created_at、预处理配置、tags、notes、**metrics JSON**（1/5/10/20 日 × 训练/验证/观察段的全部指标，ICIR 置顶）；
- **因子值矩阵**与 **IC 序列**存 `artifacts\factor_values\{id}.parquet`（供相关性查重与 UI 画图，单因子约 25–55 MB，压缩后更小）；
- `FactorLibrary` API：`add / get / list / update(改名/备注/标签/状态) / delete(默认软删归档，可硬删连带 parquet) / reevaluate(表达式反解重算)`；
- 手工添加入口：允许用户在 Web 界面输入表达式字符串，走同一评估+入库管道。
